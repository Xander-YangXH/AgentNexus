# 0013 - 模型供应商：DeepSeek（Anthropic 兼容格式），默认关闭思考模式

**状态**：已决定（2026-10-21）。用户决定使用 DeepSeek，不考虑 OpenAI / Anthropic 官方（价格原因）；格式与思考模式的选择基于下面的实测。

**背景**：此前只用真实 key 验证过 Gemini（免费档，实测首字延迟 7~173 秒、两次 503 过载）。模型工厂的 `openai`、`anthropic` 分支只验证过“能构造客户端”。DeepSeek 同时提供 OpenAI 兼容与 Anthropic 兼容两种接口，价格相同。

## 关键事实（来自官方文档，2026-10-21 查阅）
- **模型 ID 是 `deepseek-flash`**，官方说明由 DeepSeek-V4.1-Flash-1017 提供服务。展示名不能直接当 `model` 填；旧名 `deepseek-v4-flash` 仍可用但会被转发。
- 地址：OpenAI 格式 `https://api.deepseek.com`，Anthropic 格式 `https://api.deepseek.com/anthropic`。
- **思考模式默认开启、强度为 high**。OpenAI 格式下思考内容在非标准字段 `reasoning_content`；Anthropic 格式下是 `thinking` 内容块。文档写明：带工具时必须把每一轮的思考内容传回，否则返回 400。
- 价格（每百万 token，美元，`deepseek-flash`，高峰 / 闲时）：输入命中缓存 0.006 / 0.003，未命中 0.3 / 0.15，输出 1.2 / 0.6；两种格式同价；无免费额度；上下文 1M。

## 实测（真实 DeepSeek，总计约 25 次调用）

| | Anthropic 格式 | OpenAI 格式 |
|---|---|---|
| 调通 | 是 | 是 |
| 思考内容 | **作为 `thinking` 内容块保留在消息里** | 被 LangChain 的 ChatOpenAI 丢弃（拿不到），但仍计费 |
| 返回内容类型 | 开启思考时是内容块列表；关闭时是字符串 | 字符串 |
| 首个正文字（开启思考） | 2.66 秒（之前约 2 秒都是思考块） | 2.47 秒 |
| 首个正文字（关闭思考） | 0.66~0.72 秒 | 0.34~0.44 秒 |
| 回答“1+1”的输出 token | 开启：27；关闭：**1** | 开启：30（明细显示其中 **28 个是思考**）；关闭：**1** |
| 前缀缓存 | 同一长前缀第二次命中 2176 / 2409 | 同样命中，且两种格式**共享缓存** |
| 开着思考做一次工具往返 | 成功 | **也成功**（文档所说的 400 在这个场景没有复现） |

## 决定

1. **默认使用 Anthropic 兼容格式**（`LLM_PROVIDER=anthropic`、`LLM_BASE_URL=https://api.deepseek.com/anthropic`）。理由：思考内容以标准内容块保留，阶段 4 做工具调用、多轮往返时能原样传回，不依赖 LangChain 对非标准字段的处理；我们的 `message_text` 本来就只取 `text` 块。OpenAI 格式同样可用，作为备选。
2. **默认关闭思考模式**（新增配置 `LLM_THINKING=enabled|disabled`，不设置则用供应商默认）。思考 token 按输出计费，普通聊天关闭后输出 token 少一个数量级、首字快 3~4 倍。需要更强推理的 Agent（阶段 4）可单独开启。
3. **工厂补齐 `anthropic` 分支的 `base_url`**：此前只能连 Anthropic 官方地址。
4. **前缀缓存抵消“每次重发全量历史”的成本**：决策 0006 让每次执行都带完整历史，这部分是每轮相同的前缀，能命中缓存，按价格表命中的输入便宜 50 倍。

## 后果
- 好处：首字延迟从 Gemini 的数秒~数分钟降到 1 秒以内；成本可控；openai / anthropic 两个分支都有了真实调用验证。
- 代价：付费（无免费额度）；关闭思考后复杂推理能力下降。
- 待验证：文档所说的“带工具必须传回思考内容”在什么条件下触发（本次单轮工具往返未复现），阶段 4 做多轮工具调用时再测；思考 token 的计费在 Anthropic 格式的用量里没有单独列出。

## 验证
- 单元测试：思考开关进入请求体（两种格式）、非法取值与 Gemini 分支报配置错误、Anthropic 兼容地址生效。
- 冒烟脚本（已修正统计口径，见 dev-log）：两种格式 × 开启 / 关闭思考。
- 完整服务链路（Anthropic 格式、关闭思考）：首个 token 0.72 秒，回复落库，遵守系统提示词。
